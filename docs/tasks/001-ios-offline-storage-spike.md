# TASK-001: Проверка офлайн-хранения видео на iPhone

## Цель

Проверить, может ли PWA скачать видео, сохранить его на устройстве и воспроизвести без интернета на iPhone.

## Что нужно проверить

- установка PWA на домашний экран;
- скачивание тестового MP4;
- сохранение видео локально;
- воспроизведение после отключения интернета;
- сохранность видео после закрытия и повторного открытия PWA;
- отображение занятого объёма;
- ручное удаление сохранённого видео.

## Подход

Использовать:

- React;
- TypeScript;
- Vite;
- PWA;
- Cache Storage для видео;
- IndexedDB для метаданных.

Для этого эксперимента полноценный Next.js не нужен.

## Вне задачи

- Backend API;
- Instagram Collector;
- авторизация;
- PostgreSQL;
- Redis;
- Celery;
- MinIO;
- полноценный дизайн ленты;
- несколько устройств.

## Критерии готовности

Эксперимент считается успешным, если на реальном iPhone:

1. PWA устанавливается на домашний экран.
2. Тестовое видео скачивается по кнопке.
3. Видео открывается без интернета.
4. Видео остаётся доступным после перезапуска приложения.
5. Пользователь может удалить сохранённое видео.
6. Результаты проверки записаны в документацию.

# Architecture

Предварительная схема:

PWA на iPhone
→ Backend API
→ очередь роликов
→ Instagram Collector
→ Media Downloader
→ хранилище видео

## Основные правила

- Instagram-сессия хранится только на сервере.
- Телефон работает только с нашим Backend API.
- В офлайн-режиме видео читаются из локального хранилища.
- Instagram-интеграция должна быть отделена от основной логики приложения.
